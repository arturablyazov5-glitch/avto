## 1. Домен, HTTPS, зеркала
- [ ] Выбрать ОДНО главное зеркало (www или без www), второе 301-редиректом. http на https 301.
- [ ] Сертификат (Let's Encrypt/хостинг), автопродление. Mixed content нет (проверить консоль).
- [ ] HSTS можно позже, после проверки.
- [ ] Страница `index.html` отдаётся по `/` (без `/index.html`), `/index.html` 301 на `/` или canonical. Ссылки внутри на `/`.
- [ ] Домен: желательно .ru (гипотеза: для Яндекса региональный сигнал проще; решение владельца). Нужно от владельца: домен.

## 2. robots.txt
Текущий /home/user/new/robots.txt (не правил):
```
User-agent: *
Allow: /

# TODO: домен пока неизвестен, добавить после запуска:
# Sitemap: https://DOMAIN/sitemap.xml
```
Предложения (после запуска, для Савелия/прораба):
```
User-agent: *
Allow: /
Disallow: /agent-context/
Disallow: /direct/
Disallow: /seo/
Disallow: /legal/internal/

Clean-param: utm_source&utm_medium&utm_campaign&utm_content&utm_term&yclid&gclid&_openstat&fbclid /

Host: не нужен (директива устарела, главное зеркало задаётся редиректом и в Вебмастере)

Sitemap: https://DOMAIN/sitemap.xml
```
Замечания:
- Лучше НЕ выкладывать на прод папки `agent-context/`, `direct/`, `seo/`, `PROGRESS.md`, а не закрывать их robots (robots не защита, а в отчёте виден путь). Деплой: только `index.html`, `img/`, иконки, manifest, robots, sitemap, `privacy.html` и нужное от Феофана.
- Директива `Clean-param` понимается Яндексом; Google её игнорирует (в Google это решает canonical). Синтаксис проверить в Вебмастере «Инструменты → Анализ robots.txt» (раздел может называться иначе).
- `Disallow` для CSS/JS не ставить.
- Строка `Sitemap:` содержит абсолютный URL.
- Для staging: отдельный `Disallow: /` и пароль (на прод не переносить).

- [ ] Ответ 200, TTFB стабильный. Размер HTML малый (сейчас index.html ~45 КБ, `ls` 2026-10-08).
- [ ] Один canonical на `https://DOMAIN/`.
- [ ] Индексация не мгновенна; сроки не обещаем. Ускорители: Вебмастер «Переобход», ссылка из карточки Бизнеса, внешние упоминания (plan.md).

## 7. Скорость и Core Web Vitals
Подтверждено локально: img/ содержит front.jpg и front-hd.jpg (одно и то же фото 960x1280 и 1440x1920), og.jpg 96 КБ. Проверить размеры: `ls -la img/`.
- [ ] Фасад: WebP (и/или AVIF) + JPEG fallback через `<picture>`, `srcset` 960/1440, `width`/`height`, цель ≤ 150-200 КБ на мобильный вариант (ориентир, не требование; проверить в PageSpeed).
- [ ] LCP-изображение: без `loading="lazy"`, с `fetchpriority="high"`; остальные lazy.
- [ ] Шрифты: системные или preload+`font-display: swap`; не тащить лишние начертания.
- [ ] CSS/JS: инлайн критического, остальное минимально; скрипты Метрики `async`.
- [ ] CLS: размеры у картинок, не прыгает блок после загрузки.
- [ ] Метрики: Lighthouse/PageSpeed Insights (https://pagespeed.web.dev/) на мобильном; зелёные CWV (LCP < 2,5 с, INP < 200 мс, CLS < 0,1: общепринятые пороги Google, проверить на https://web.dev/vitals/).
- [ ] Кэширование статики (заголовки `Cache-Control`), gzip/brotli.
- [ ] Сайт грузится быстро на мобильном 4G (основной трафик локальный/мобильный: гипотеза).

## 9. Страница 404 и мелочь
- [ ] Кастомный 404 (статус реально 404, не 200): ссылка на главную, телефон. Файл `404.html`, `noindex`.
- [ ] Favicon есть (favicon.ico, favicon.svg, apple-touch-icon.png, site.webmanifest от Савелия): проверить `<link>` в head и размеры 48x48+ для Яндекса (рекомендация Яндекса: favicon.ico и/или svg, не менее 120x120 для показа в выдаче, проверить в справке «Фавикон»).
- [ ] Заголовки безопасности: `X-Content-Type-Options`, `Referrer-Policy` (по возможности).
- [ ] Убрать `/index.html` из sitemap, дубли `/?utm`.
- [ ] Страницы privacy/cookie: ссылка из футера, `rel` по смыслу, не `noindex` (Яндекс любит, но по гипотезе нужна).

## 11. Предзапусковая проверка (быстро)
1. `curl -I https://DOMAIN/` → 200; `curl -I http://DOMAIN/` → 301 на https.
2. `/robots.txt` и `/sitemap.xml` открываются.
3. View-source: title, description, canonical, JSON-LD, alt.
4. Rich Results Test + Яндекс валидатор: без ошибок.
5. Вебмастер: сайт добавлен, sitemap отправлен.
6. Метрика: цели срабатывают (тестовый клик).
7. PageSpeed мобильный: сохранить скрин для сравнения.
