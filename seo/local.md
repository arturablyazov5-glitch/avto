## 6. Как привязать лендинг к карточке (двусторонне)

1. В карточке Яндекс Бизнеса и 2ГИС в поле «Сайт» указать главный URL лендинга (с UTM, раздел 7).
2. На лендинге: NAP текстом (название, адрес, телефон, WhatsApp) + кнопка «Как доехать» на https://yandex.ru/maps/org/205484445084 + ссылка на отзывы на Картах + JSON-LD `AutoRepair` с `sameAs` на карточку (готов в onpage.md).
3. В Яндекс Вебмастере: подтвердить сайт, раздел «Информация о сайте» / «Сайт для организации» (проверить название в интерфейсе): указать организацию из Яндекс Бизнеса. Список организаций Яндекс собирает по данным робота и из Бизнеса (подтверждено поиском 2026-10-08, справка https://www.yandex.ru/support/webmaster/ru/search-appearance/organization). Размещение разметки на сайте не гарантирует показ данных (там же).
4. Тот же сайт в Google Search Console + ссылка в профиле Google.
5. Телефон на сайте в `tel:` ссылке, тот же номер в карточках.

## 7. UTM для ссылок из карточек

Технически UTM-метки в поле «Сайт» допустимы (пользователи так делают; официальную страницу про UTM в Бизнесе не нашёл, поиск 2026-10-08, проверить руками). Важно: URL с UTM должен отдавать главную и не создавать дубль (canonical в onpage.md указывает на чистый URL; в index.html canonical без параметров).
- Яндекс Карты/Бизнес: `https://DOMAIN/?utm_source=yandex&utm_medium=organic&utm_campaign=business_card`
- 2ГИС: `https://DOMAIN/?utm_source=2gis&utm_medium=organic&utm_campaign=card`
- Google профиль: `https://DOMAIN/?utm_source=google&utm_medium=organic&utm_campaign=gbp`
- Кнопка WhatsApp на сайте: без UTM, цель в Метрике.
- В Яндекс Директе (Ипполит) метки свои, не смешивать с органикой.
- В Метрике цель на звонок/клик: `tel:` и `wa.me` (см. technical.md).
Дубли: в Вебмастере/Метрике параметры `utm_*` добавить в «Исключаемые параметры» (в robots.txt директива Clean-param, см. technical.md).

- Отзывы собирать только честно: просить довольных клиентов оставить отзыв QR-кодом/ссылкой на карточку (ссылка из кабинета). Не обещать вознаграждение.
- Не вводить «NAP-спам» (дубли каталогов с разными названиями).
- Нужно от владельца: дополнительный номер, право на фото с Карт, подтверждение услуг (электрика, проточка), доступ к карточкам.
